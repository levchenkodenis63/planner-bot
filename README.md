# Telegram-бот «Планировщик задач»

Распределяет рабочий день между проектами и постерами и учитывает съёмки и дни в дороге.
Работает на Cloudflare Workers, данные хранит в D1 (это SQLite). Укладывается в бесплатный тариф.

## Как он планирует

Каждый рабочий день (по умолчанию 8 ч с 10:00) заполняется в таком порядке:

1. **Срочные постеры.** Сюда попадают постеры, которые нельзя отложить: если срок выпадает на съёмку, дорогу
   или выходной, бот берёт последний рабочий день перед ним. Помечаются 🔥.
2. **Проекты**: сколько часов в день вы указали каждому (например, 3 + 3).
   Если срочные постеры заняли часть дня, время проектов пропорционально урезается (*урезано*).
3. **Остальные постеры** в порядке срока, а при одинаковом сроке — по времени поступления.
   Если постер не помещается целиком, он делится на несколько дней (*часть*).
4. **Буфер**: всё оставшееся время.

Дни съёмки и дни дороги туда и обратно полностью свободны от других задач.
Если постер не успевает к сроку, бот предупредит ⚠️ — в `/posters`, в плане и сразу после добавления съёмки.

План не хранится, а пересчитывается при каждом запросе из текущих данных. Отметили постер готовым или
добавили выезд — следующий `/today` уже это учтёт.

## Установка (≈10 минут)

Нужен Node.js 18 или новее.

```bash
npm install
npx wrangler login
```

1. **Бот.** Создайте его у [@BotFather](https://t.me/BotFather) командой `/newbot` и сохраните токен.

2. **База D1.**
   ```bash
   npx wrangler d1 create planner-bot
   ```
   Скопируйте `database_id` из ответа в `wrangler.toml`.
   > Можно взять D1 из вашего существующего проекта, но таблицы называются `settings`, `projects`,
   > `posters`, `shoots`, `project_tasks`. Если такие имена уже заняты, будет конфликт.
   > Надёжнее отдельная база: это бесплатно.

3. **Таблицы:**
   ```bash
   npm run db:init:remote
   ```

4. **Секреты** (каждая команда спросит значение):
   ```bash
   npx wrangler secret put BOT_TOKEN        # токен от BotFather
   npx wrangler secret put ALLOWED_USER_ID  # ваш Telegram ID
   npx wrangler secret put WEBHOOK_SECRET   # любая строка из A-Z a-z 0-9 _ -
   ```
   Не знаете свой ID? Поставьте временно `0`, задеплойте и напишите боту: он ответит вашим ID.
   Потом повторите `secret put ALLOWED_USER_ID`.

5. **Деплой:**
   ```bash
   npm run deploy
   ```

6. **Подключение к Telegram.** Один раз откройте в браузере:
   `https://planner-bot.<ваш-субдомен>.workers.dev/setup?key=<WEBHOOK_SECRET>`
   Должны прийти `"ok": true` для webhook и для команд.

7. Напишите боту `/start`. Это обязательно: так бот запоминает чат для утренних сообщений.

## Обновление (если бот уже развёрнут)

Версия со сроками задач добавляет колонку в базу. Миграцию нужно запустить один раз, до деплоя:

```bash
npm run db:migrate:remote   # добавляет срок задачам; у старых задач — дата создания + 7 дней
npm run deploy
```
Повторный запуск миграции выдаст ошибку `duplicate column` — это значит, что она уже применена.

## Первые шаги

```
/project Сайт для Альфы | 3 | 31.01
/project CRM для Беты | 3 | 15.02
/set off вс
/trip 29.11-30.11 | Казань, чемпионат | 1 | 1
/shoot 06.12 | Кубок Самары
```

**Постеры.** Перешлите боту сообщение клиента: он создаст заказ с именем и @username и спросит срок кнопками.
Если от того же клиента в течение 3 минут придут ещё сообщения (номер, фото с подписью), они допишутся
к тому же заказу. Нужен второй постер тому же человеку? Добавьте его вручную:

```
/poster Иванов | марафон 10 км, номер 128 | 25.11
/poster Петрова | полумарафон | 26.11 | 2
```
Каждая строка — отдельный постер, поэтому после соревнований можно вставить сразу весь список.

**Задачи проектов** со сроком (без срока — через неделю):
```
/task сайт | Авторизация | 25.11
/task crm | Схема БД
Отчёты | 01.12
```
В плане дня у каждого проекта показаны две задачи с ближайшим сроком (просроченные — с ⚠️),
а первым в дне идёт проект, у которого ближе всего срок задачи. Срок меняется командой `/taskdate 5 28.11`.

Кнопки внизу экрана: 📅 Сегодня · ➡️ Завтра · 🗓 Неделя · 🖼 Постеры · 📸 Съёмки · 💼 Проекты.
В 🖼 Постеры у каждого заказа есть кнопки ✅ (готов) и ▶️ (в работе).
Полный список команд — `/help`.

## Утренний план

Cron запускается каждый час и в первый запуск после `notify_time` (по умолчанию 08:00 по Самаре)
присылает план на день и предупреждает о ближайших съёмках и дорогах. Время меняется командой
`/set notify 07:00`, отключается — `/set notify off`.
Часовой пояс задаётся в `wrangler.toml` (`TZ_OFFSET_MIN = "240"` — это UTC+4).

## Разработка

```bash
npm test     # тесты планировщика и сквозной сценарий бота на SQLite
npm run dev  # локальный запуск; секреты положите в .dev.vars (см. .env.example)
```

Файлы:
- `src/planner.js` — алгоритм распределения (чистая функция без зависимостей)
- `src/bot.js` — команды, кнопки, пересланные сообщения, утренняя рассылка
- `src/db.js` — запросы к D1
- `src/format.js` — оформление сообщений
- `src/index.js` — точка входа Worker (webhook, /setup, cron)
